# yomi-boot-admin

一个企业级管理后台的脚手架，前后端分离，开箱即用，可以直接在上面加业务模块。

## 组成

| 目录 | 说明 |
|---|---|
| `yomi-admin-backend/` | 后端，Go + [yomi-boot](https://github.com/hwwadmin/yomi-boot) |
| `yomi-admin-web/` | 前端，Vue 3 + TypeScript |


更细的说明看 [后端 README](yomi-admin-backend/README.md) 和 [前端 README](yomi-admin-web/README.md)。
