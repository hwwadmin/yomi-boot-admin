# 新增业务模块流程

> 示例：公告 `notice`（标题、内容、启停）。
> 一句话：**一个业务模块 = 一个独立 domain module + usecase + handler + 页面 + 权限/菜单 + OpenAPI**。
> 代码只给骨架，完整写法照 `domains/sysparam` 抄。

## 0. 先定契约（10 分钟）

| 项 | 示例 |
|---|---|
| 资源名 | `notice`（单数、小写；接口路径 `/api/notice`） |
| 字段 | `id`、`title`、`content`、`status`、`createTime`、`updateTime` |
| 接口 | 列表、详情、创建、更新、删除、启停 |
| 权限码 | `notice:list`、`notice:detail`、`notice:create`、`notice:update`、`notice:delete`、`notice:status` |
| 菜单 | `code=notice`，`uiPath=/notice` |

先定这些，是因为 OpenAPI、权限目录、前端 API/路由都按它抄，后面不用返工。

## 2. 后端 domain：`domains/notice`

```text
domains/notice/
├── go.mod
├── pkg/shared/{entity,enums,input,output}/
├── internal/repo_contract/
├── internal/repo/{model,mapper,repo}.go
├── internal/service/
├── service_contract/
└── provider/module.go
```

各层只干一件事：

- `pkg/shared`：本域公开类型，跨模块只认它；
- `repo_contract`：存储接口，不碰 gorm；
- `internal/repo`：真正碰数据库；
- `internal/service`：业务规则；
- `service_contract`：给 apps 用的接口；
- `provider`：装配入口，只给 bootstrap 用。

### 2.1 公开类型

```go
// entity：ID int64，时间 Unix 毫秒
type Notice struct {
    ID         int64
    Title      string
    Content    string
    Status     enums.Status
    CreateTime int64
    UpdateTime int64
}

// enums：大写字符串；照 sysparam 的 Status 写 Normalize + UnmarshalJSON 校验
type Status string
const (
    StatusEnabled  Status = "ENABLED"
    StatusDisabled Status = "DISABLED"
)

// input：写操作带 OperatorID
type PageNoticesInput struct { Keyword string; Status enums.Status; Page, PageSize int }
type CreateNoticeInput struct { Title, Content string; OperatorID int64 }
type UpdateNoticeInput struct { ID int64; Title, Content string; OperatorID int64 }
type SetNoticeStatusInput struct { ID int64; Status enums.Status; OperatorID int64 }
type DeleteNoticeInput struct { ID int64; OperatorID int64 }

// output
type PageNoticesOutput struct { Items []*entity.Notice; Total int64 }
```

### 2.3 业务与对外契约

```go
type NoticeService struct {
    repo repo_contract.NoticeRepo
    ids  snowflake.Generator
}
var _ service_contract.NoticeService = (*NoticeService)(nil)

func (s *NoticeService) Create(ctx context.Context, in *input.CreateNoticeInput) (*entity.Notice, error) {
    if in == nil || strings.TrimSpace(in.Title) == "" {
        return nil, errors.Sentinel(service_contract.ErrInvalidInput)
    }
    id, err := s.ids.NextID()
    if err != nil {
        return nil, errors.Wrap(err, "生成公告 ID 失败")
    }
    notice := &entity.Notice{
        ID: id, Title: strings.TrimSpace(in.Title), Content: in.Content,
        Status: enums.StatusEnabled,
    }
    if err := s.repo.Create(ctx, notice, in.OperatorID); err != nil {
        return nil, err
    }
    return notice, nil
}
```

```go
// service_contract
type NoticeService interface {
    Page(ctx context.Context, in *input.PageNoticesInput) (*output.PageNoticesOutput, error)
    Get(ctx context.Context, id int64) (*entity.Notice, error)
    Create(ctx context.Context, in *input.CreateNoticeInput) (*entity.Notice, error)
    Update(ctx context.Context, in *input.UpdateNoticeInput) error
    SetStatus(ctx context.Context, in *input.SetNoticeStatusInput) error
    Delete(ctx context.Context, in *input.DeleteNoticeInput) error

var (
    ErrNoticeNotFound = errors.NewBiz("ADMIN_NOTICE_NOT_FOUND", "公告不存在")
```

## 3. 后端 apps：usecase + handler + wire

### 3.1 usecase

放 `apps/server/internal/usecase/notice/`，一个动作一个文件。

```go
type CreateNoticeInput struct {
    Title      string `json:"title"`
    Content    string `json:"content"`
    OperatorID int64  `json:"-"`
}

// 更新/删除/启停的 HTTP 入参：ID 用 dto.JSONInt64 接前端字符串，再 .Int64() 转给 domain
type UpdateNoticeInput struct {
    ID         dto.JSONInt64 `json:"id"`
    Title      string        `json:"title"`
    Content    string        `json:"content"`
    OperatorID int64         `json:"-"`
}

func (uc *CreateNoticeUsecase) Execute(ctx context.Context, in *CreateNoticeInput) (*NoticeItem, error) {
    notice, err := uc.notices.Create(ctx, &noticeinput.CreateNoticeInput{
        Title: in.Title, Content: in.Content, OperatorID: in.OperatorID,
    })
    if err != nil { return nil, err }
    item := toNoticeItem(notice)
    return &item, nil
}
```

分页用例用 `dto.PageInput.ValiPage()` + `dto.NewPageOutput`；视图 `NoticeItem` 的 ID 用 `dto.JSONInt64`。

### 3.2 handler

```go
func (h *NoticeHandler) Routes(r *gin.RouterGroup) {
    r.GET("/api/notice", h.page)
    r.GET("/api/notice/detail", h.get)
    r.POST("/api/notice/create", h.create)
    r.POST("/api/notice/update", h.update)
    r.POST("/api/notice/delete", h.delete)
    r.POST("/api/notice/set-status", h.setStatus)
}

func (h *NoticeHandler) page(c *gin.Context) {
    in := &noticeusecase.PageNoticesInput{
        PageInput: dto.PageInput{Page: queryInt(c, "page", 1), PageSize: queryInt(c, "pageSize", 10)},
        Keyword:   c.Query("keyword"),
        Status:    noticeenums.NormalizeStatus(c.Query("status")),
    }
    handle(c, func(ctx context.Context) (dto.PageOutput[noticeusecase.NoticeItem], error) {
        return h.pageUC.Execute(ctx, in)
    })
}
```

约定：查询 `GET`、变更 `POST`；不用路径参数；ID 放 query/body；统一走 `handle` / `handleVoid`；`BindJSON` + `operatorID`。

## 5. OpenAPI 与权限

- `apps/server/api/openapi.yaml` 6 条路由一条不能少；`TestAPIDocCoverage` 会双向对账。写法照 `/api/system/param` 段。
- 权限是数据，不是代码常量。在权限管理页加：

| code | type | uiPath / HTTP |
|---|---|---|
| `notice` | MENU | `/notice` |
| `notice:list` | API | `GET /api/notice` |
| `notice:detail` | API | `GET /api/notice/detail` |
| `notice:create` | API | `POST /api/notice/create` |
| `notice:update` | API | `POST /api/notice/update` |
| `notice:delete` | API | `POST /api/notice/delete` |
| `notice:status` | API | `POST /api/notice/set-status` |

再把权限绑到权限组、角色绑到权限组；超管 `*` 跳过。用种子 SQL 的话照 `020_rbac.sql` 补，本文不展开。

## 6. 前端

前端在 `../yomi-admin-web`。

**api**：`src/api/notice.ts`

```ts
export async function getNoticePage(params: NoticeQuery) {
  const { list, total } = await requestPage<NoticeItem>({ url: '/notice', method: 'get', params })
  return { list, total, page: params.page, pageSize: params.pageSize }
}
export function createNotice(data: NoticeCreatePayload) {
  return request<NoticeItem>({ url: '/notice/create', method: 'post', data })
}
// update / delete / set-status 同理，路径与后端一致
```

**类型**：`src/api/types.ts` 追加 `NoticeItem`（`id: string`）、`NoticeQuery extends PageQuery`、`NoticeCreatePayload`、`NoticeUpdatePayload`。

**页面**：`src/views/notice/index.vue`，最快是复制 `src/views/system/param/index.vue`，替换字段和接口；外层 `PageCard`，时间 `formatDateTime`，删除 `confirmAction`，按钮 `v-permission`。

**路由**：`src/router/routes.ts` 根路由 `children` 加：

```ts
{ path: 'notice', name: 'notice',
  component: () => import('@/views/notice/index.vue'),
  meta: { titleKey: 'menu.notice', icon: 'Bell' } }
```

**i18n**：两种语言的 `menu.json` 加 `notice`；新建 `notice.json` 并在 `index.ts` 挂到根节点。新图标要在 `src/utils/menuIcons.ts` import + 映射，否则侧栏没图标。

后端新增错误码后：`pnpm sync:error-codes`，再补两种语言 `errors.json` 的 `codes`。

**mock（可选）**：路径必须和真实接口一致，别照抄 `mock/index.ts` 里的旧 REST 路径。

## 9. 常见坑

1. apps 不能 import `domains/*/internal`，只能 `service_contract` / `pkg/shared`；
2. handler 不能跳过 usecase 直接依赖 domain；
3. ID 不用 `dto.JSONInt64`，前端会丢精度；
4. 时间单位不统一，实体和接口统一 Unix 毫秒；
5. 分页返回 `data` 直接是数组，当前协议是 `{ items, total }`；
6. 用路径参数，本项目只用 GET/POST，ID 放 query/body；
7. 漏写 OpenAPI，`TestAPIDocCoverage` 直接失败；
8. 只加后端菜单不加前端路由（或反过来），页面不可达/侧栏不显示；
9. 把后端 `msg` 显示到界面，前端只按 `code` 走 i18n；
10. 新增域没改 `.golangci.yml` / `go.work` / `go.mod`，编译或 lint 莫名失败。

部门/岗位/字典/OSS/通知这类项目相关能力，不要照普通模块硬塞进 user/RBAC；按可选模块另做，内核只留扩展点。
